### CVE-2026-115585 — pypdf

<img src="https://img.shields.io/badge/Severity-HIGH_7.1-critical?style=for-the-badge&logo=github&logoColor=white" />
<img src="https://img.shields.io/badge/CWE--400-Uncontrolled_Resource_Consumption-red?style=for-the-badge" />
<img src="https://img.shields.io/badge/CWE--407-Inefficient_Algorithmic_Complexity-orange?style=for-the-badge" />

</div>

**Discovered and reported** an uncontrolled resource consumption (DoS) vulnerability caused by algorithmic complexity during malformed cross-reference parsing.

- **Impact**: Crafted cross-reference streams could force repeated full PDF stream reloads, leading to extremely long runtimes and denial of service.
- **Fixed in**: `pypdf` 6.21.2
- **Advisory**: [GHSA-jr96-gvgh-j3r4](https://github.com/advisories/GHSA-jr96-gvgh-j3r4)
- **CVE**: [CVE-2026-115585](https://www.cve.org/CVERecord?id=CVE-2026-115585)

> This is a follow-up to a previous incomplete remediation. The issue was triggered by carefully crafted malformed cross-reference entries that bypassed the recovery cache.
